# Arstbot-QQbotmood

给 AstrBot 的机器人加「情绪」和「好感度」两个插件：心情会随时间掉、会因为你说话变好，
好感度把心情、亲密度、相处天数、承诺和聊天量合成一个 0-100 的分数。


## 两个插件

| 目录 | 作用 | 命令 |
| --- | --- | --- |
| `plugins/astrbot_plugin_mood` | 心情 / 亲密度 / 想黏人，跨轮次保存，会衰减 | 无（自动注入上下文） |
| `plugins/astrbot_plugin_affection` | 把上面那些合成分数 | `/好感度` |

## 数据存哪

全部是纯文件，没有数据库：

```
astrbot/data/mood/<会话>.json          心情/亲密/想黏（mood 插件写）
astrbot/data/chat_bridge/messages.jsonl 聊天流水（用于统计条数，可选）
astrbot/data/memory/promises.md         答应过的事（每行以 "- " 开头，可选）
```

## 安装

1. 把 `plugins/` 下两个目录复制到 `astrbot/data/plugins/`
2. 重启 AstrBot（插件只在启动时加载）
3. 改 `astrbot_plugin_affection/main.py` 里的：
   - `FIRST_DAY`：你们认识的日子
   - `MOOD_FILE`：你自己的会话文件名（`astrbot/data/mood/` 下找 `qqbot_FriendMessage_<QQ号>.json`）

## 规则细节

### mood（情绪）

| 事件 | 影响 |
| --- | --- |
| 被夸（厉害/真棒/可爱/喜欢你…） | 心情 +6，亲密 +4 |
| 被凶（滚/闭嘴/没用/蠢…） | 心情 −10，亲密 −4 |
| 被敷衍（只有「嗯」「哦」「随便」） | 心情 −7，被敷衍计数 +1 |
| 说亲近的话（抱/摸头/亲/想你了/贴/蹭/黏） | 想黏 **+20**，亲密 +5，心情 +3 |
| 普通聊天 | 想黏 −1（这句有亲近词就不扣） |
| 多久不说话 | 每小时：心情 −2、亲密 −0.8（保底 40）、想黏 +1.5 |

想黏三档：<45 没那个心思、45–69 有点想亲近、≥70 很想黏人。

### affection（好感度）

```
基础分（上限 75） = 亲密×0.40 + 心情×0.25 + min(想黏,100)×0.10
相处加成（上限 29）= min(天数×1.2, 15) + min(流水条数/40, 6) + min(承诺数×2, 8)
最终 = clamp(基础分 + 加成, 0, 100)
```

档位：<20 生疏 / <40 有点熟 / <60 还行 / <75 挺亲近 / <90 黏上你了 / ≥90 离不开了

## 示例

```
好感度 72/100 ███████░░░ 挺亲近的
心情 94/100　亲密 99/100
想黏 0/100（没那个心思）
相处 2 天　流水 106 条　承诺 2 件
```
